# Mawidi updates

Release files for Mawidi (موعدي). Installed copies of Mawidi read the `releases` folder and update themselves when
no meeting is near. This repository holds no source code and no personal data.

**Latest version: 0.5.0.** To install Mawidi on a new PC, download
[MawidiApp-win-Setup.exe](https://github.com/Ahmedz95/mawidi-updates/raw/main/releases/MawidiApp-win-Setup.exe) and
run it. It is not code-signed yet, so Windows SmartScreen asks first: click "More info", then "Run anyway".
